# Plateforme E-commerce — Produits Traditionnels

Plateforme e-commerce mono-vendeur pour produits traditionnels/culturels.

## Stack

- Backend : Spring Boot (Java 21)
- Frontend : Vue 3 + TypeScript + Vite
- Base de données : PostgreSQL
- Déploiement : Docker Compose + Nginx

## Structure du repo

\`\`\`
backend/ → API Spring Boot
frontend/shop/ → Site public (Vue 3)
frontend/admin/ → Back-office (Vue 3)
infra/ → Docker, Nginx, configs de déploiement
docs/ → Documentation technique, ADR
\`\`\`
